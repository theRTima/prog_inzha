# prog_inzha

Репозиторий приложения для Программной инженерии.

Система по типу 1С на Qt и Python.

# Для запуска

1)docker-compose up -d

2)Запустить reset_database.py

3)Запустить test_data.py (Опционально, для заполнения тетовыми данными)

4)Запустить main.py
